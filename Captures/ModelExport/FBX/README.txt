SpeedStart - Geometry Only FBX

48 FBX models. No materials, textures, animations or Unity scripts.
Units: meters. Unity import root scale: 1,1,1; root rotation: 0,0,0.
Individual mesh parts and UV coordinates are retained.
Clouds and 2D hedge geometry are excluded.
Some windows and surface detail in the background skyline were shader effects; they are not mesh geometry and are not included.
ModelList.csv lists each FBX, its Unity source, and geometry counts.

UNITY PREFAB UPDATES
An FBX with the same name does not automatically replace an existing .prefab or a Unity .asset mesh.
First connect the FBX model/meshes inside the existing prefab, retaining its scripts and material assignments as needed.
After this initial connection, overwrite that same FBX inside Assets to update it. Keep the .meta file.
Keep mesh/object names and hierarchy stable to avoid broken sub-asset references.
Files in this external delivery folder are not automatically imported by Unity.

The existing project scene and prefab model references were not replaced during this export.
